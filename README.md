# rune-hub
rune-hub 是一个面向开发者的轻量级 AI 应用编排引擎，核心理念是"嵌入而非接管"。 rune-hub 不内置用户体系、不做 RBAC，而是通过 AppId + HMAC 签名提供开放接口，让你直接将其挂入已有业务系统，零迁移成本。 前端提供 ReactFlow 拖拽式 DAG 画布，将 LLM 调用、工具执行、条件分支等节点自由串联为独立 AI 应用。 全链路支持节点级执行轨迹、输入输出、Token 消耗追踪，并支持多租户维度的用量统计与预算管控。模型、工具、MCP 服务器均不锁定，市面主流格式开箱兼容。宗旨实现像 SDK 一样嵌入你的业务，而不是让你搬进另一个平台。
